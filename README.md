
# 🚀 MiniCoders – Learn Coding Through Play

MiniCoders is an interactive coding-learning platform designed for kids to make programming fun, engaging, and accessible. Children can learn programming concepts through interactive games, solve coding challenges, participate in coding contests, and get assistance from an AI-powered learning assistant.

Our goal is to transform traditional coding education into an enjoyable, game-based learning experience.

## 🌐 Live Demo

**Frontend:** [MiniCoders Live](https://mini-coders-client.vercel.app)

## 🛠️ Technology Stack

| Technology | Purpose |
|---|---|
| Next.js | Frontend Development |
| React.js | UI Development |
| TypeScript | Type Safety |
| Node.js | Backend Runtime |
| Express.js | Backend Framework |
| PostgreSQL | Relational Database |
| Prisma ORM | Database Management |
| SQL | Database Query Language |
| Tailwind CSS | Styling |

## ✨ Features

- 🎮 **Interactive Coding Games:** Learn programming concepts through fun and engaging games.
- 🧩 **Problem Solving:** Improve logical thinking and programming skills by solving coding challenges.
- 🏆 **Coding Contests:** Participate in coding competitions and challenge other learners.
- 🤖 **AI Learning Assistant:** Get AI-powered guidance, explanations, and personalized learning support.
- 👨‍💻 **Kid-Friendly Interface:** A simple and interactive learning environment designed specifically for children.
- 📈 **Learning Progress:** Track learning activities and improve coding skills over time.
